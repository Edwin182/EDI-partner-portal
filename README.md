# EDI Partner Onboarding Portal

I’m building a web application that helps EDI consultants and their customers test EDI transactions when setting up a new trading partner. For my capstone, I’m focusing on the EDI 850 purchase order. Users will be able to test a sample order, see errors explained in plain English, and track corrections and retest results.
